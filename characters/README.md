## How the layers work
- All characters share one 400×500 canvas, with the ground line at y≈462, so they line up side by side.
- Every moving part is a separate `<g>` marked as an Inkscape layer (`inkscape:groupmode="layer"`). Inkscape, Illustrator and Affinity open these as layers. Moho, Spine, Rive and After Effects (via Illustrator) import them as separate parts.
- Each layer has a `data-pivot="x y"` attribute. Set the part's anchor/bone origin to that point (shoulder, hip, neck, tail base and so on).
- Layers are ordered back to front: `shadow`, then tail/wings/horns/ears, then legs, then the back arm, then the body or torso, then the head (hair-back, face-base, eyes, brows, mouth, blush, hair-front), then the front arm and props.
- The `eyes` layer is centered on its pivot, so scaling it to Y=0.1 makes a blink.

## Editing
The characters are generated by `build.py`, where shapes and colors are plain data. Change a color or shape, then run `python3 build.py` to rebuild every SVG and the preview.
